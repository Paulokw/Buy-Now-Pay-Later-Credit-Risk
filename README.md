# Buy-Now-Pay-Later-Credit-Risk
This is a classification project where we aim to determine the credit risk level of different users given several features.
We first conducted exploratory data analysis so as to get a better undestanding of the data while also doing data preprocessing to check for any missing values and duplicates. There after we encoded the categorical features and scaled them after which we addressed the imbalanced dataset and applied SMOTE. XGBOOST was the model used to train and test our data and confusion matrix used to evaluate the performance of the model.
